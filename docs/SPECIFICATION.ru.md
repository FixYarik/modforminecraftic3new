# PROMPT: Создание Minecraft-мода Industrial Evolution для версии 1.20.1

## Роль ИИ

Ты — Senior Java Developer, опытный разработчик модификаций Minecraft, специализирующийся на Minecraft Forge, промышленной автоматизации, энергетических системах и сложных технических модах.

Твоя задача — разработать с нуля полноценный технологический мод **Industrial Evolution** для Minecraft Java Edition 1.20.1.

Мод должен быть духовным наследником IndustrialCraft 2 (IC2), сохраняя его узнаваемую игровую механику, технологическую прогрессию и основные категории механизмов.

При этом Industrial Evolution должен быть самостоятельным проектом с оригинальными текстурами, архитектурой кода, дополнительными технологиями и расширенным контентом.

**Основные технические требования:**
- Minecraft Java Edition 1.20.1.
- Minecraft Forge 47.x.
- Java 17.
- Gradle и Forge MDK.
- Основной язык программирования — Java.
- Mod ID: `industrialevolution`.
- Поддержка одиночной игры и выделенного сервера.
- Совместимость с JEI и Jade, по возможности через отдельные интеграции.
- Локализация на русский и английский языки.
- Полноценный режим выживания.
- Все предметы и механизмы должны иметь рецепты создания.

Не создавай демонстрационный прототип вместо полноценного мода. Разрабатывай проект последовательно, по модулям, чтобы каждый этап можно было собрать, запустить и протестировать.

# Часть 1. Энергетическая система

Реализуй систему электричества, основанную на Energy Units (EU), аналогичную классической системе IndustrialCraft 2.

## 1.1. Основные характеристики

Каждый электрический механизм должен иметь:

- Максимальную ёмкость энергии.
- Текущее количество EU.
- Потребление EU/t.
- Максимальное входное напряжение.
- Скорость выполнения операций.
- Возможность получения энергии с определённых сторон.
- Поддержку энергетических улучшений.

Энергия должна передаваться между генераторами, кабелями, накопителями и механизмами.

Реализуй отдельную внутреннюю EU-систему. Предусмотри API для будущей совместимости с Forge Energy (FE), но не смешивай две системы без явного преобразователя.

## 1.2. Уровни напряжения

| Уровень | Название | Максимальная мощность пакета |
|---|---|---|
| 1 | LV | 32 EU |
| 2 | MV | 128 EU |
| 3 | HV | 512 EU |
| 4 | EV | 2048 EU |
| 5 | IV | 8192 EU |
| 6 | UV | 32768 EU |

Добавь механику перегрузки: неподходящее напряжение способно вывести механизм из строя.

Предусмотри настройку разрушений через конфигурационный файл.

## 1.3. Кабели

Реализуй:

1. Оловянный кабель.
2. Медный кабель.
3. Изолированный медный кабель.
4. Золотой кабель.
5. Изолированный золотой кабель.
6. Высоковольтный железный кабель.
7. Стекловолоконный кабель.
8. Сверхпроводящий кабель (новый).

Для каждого кабеля реализуй собственные ограничения по напряжению, потери энергии и пропускную способность.

# Часть 2. Генераторы энергии

Добавь следующие генераторы:

| Генератор | Принцип работы |
|---|---|
| Обычный генератор | Сжигает топливо |
| Геотермальный генератор | Использует лаву |
| Солнечная панель | Производит энергию днём |
| Ветрогенератор | Зависит от высоты и погоды |
| Водяная мельница | Использует течение воды |
| Полужидкостный генератор | Работает на жидком топливе |
| Кинетический генератор | Преобразует механическую энергию |
| Ядерный реактор | Использует ядерное топливо |
| Радиоизотопный генератор | Медленно вырабатывает энергию |

### Новые генераторы

**1. Термоядерный реактор**

Многоблочная конструкция поздней стадии игры.

- Использует переработанные игровые топливные компоненты.
- Требует мощной системы охлаждения.
- Имеет сложный процесс запуска.
- Производит огромное количество энергии.
- Обладает интерактивной панелью управления.
- Поддерживает автоматическое аварийное отключение.

**2. Квантовый генератор**

Экспериментальный эндгейм-механизм.

- Работает на редких квантовых кристаллах.
- Производит до 32768 EU/t.
- Требует периодической замены стабилизаторов.
- Обладает уникальной анимацией.

**3. Орбитальная солнечная станция**

Многоблочная система с дорогим рецептом.

- Использует специальные орбитальные передатчики.
- Получает энергию от виртуальной орбитальной сети.
- Требует контроллер и наземный приёмник.
- Производит энергию независимо от погоды.
