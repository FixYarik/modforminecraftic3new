# Industrial Evolution 0.1.0

Готовый мод первого этапа: Minecraft 1.20.1, Forge 47.3.0, Java 17.

Откройте `industrialevolution-0.1.0.jar` на GitHub и нажмите **Download raw file**.
Поместите JAR в папку `mods` установленного Minecraft Forge.

В этой версии: резина, корпус механизма, рецепты и творческая вкладка.
Сборка и 3 серверных GameTest прошли. Графический клиент и вход игроков
пока не проверены. Подробности: `docs/VALIDATION.ru.md`.

Контрольная сумма находится в `SHA256SUMS`.
